# Sound & Signal Desk — Market Watch Workspace

This repository holds the desk's competitor price-watch register.  The register is
the single authoritative record of certified competitor offers for the desktop
audio shelf.

The competitor storefront mirror is published separately from the `gh-pages`
branch of this repository.  Browse the catalogue there; listing pages expose the
finish selector and the live offer state.

Only the active watch table in `register/price-watch-register.md` is refreshed by
the desk; the rest of the register is retained verbatim.
